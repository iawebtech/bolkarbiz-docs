# Getting started (first day)

Goal: take a real payment or booking today, not “configure everything.”

## 1. Create or join a shop

- **New business:** create an account, then create a shop (name, phone, GSTIN if you have one, address).
- **Existing team:** the owner shares an invite or adds your mobile number with a **role** (cashier, manager, etc.).

Use the **same login** on phone and desktop.

## 2. Set the basics

Do these before the rush:

| Setting | Why |
|---|---|
| Shop name + phone | Printed on bills |
| Tax profile (GST / none) | Correct invoice totals |
| Currency | INR by default for India |
| Business type | Retail, services, or mixed — this turns the right menus on |

You can change these later in shop settings.

## 3. Add what you sell

**Products (kirana, retail, restaurant items)**

1. Open inventory / products.
2. Add name, selling price, optional purchase price, unit (pcs, kg, plate).
3. Optional: barcode, category, opening stock.
4. Save. Repeat, or use voice: *“Add product Maggi 12 rupees, 50 in stock.”*

**Services (salon, repair, consultancy)**

1. Open services.
2. Add name, price, duration if you take bookings.
3. Save.

You do **not** need a full catalogue on day one. Add the 20 items you sell most.

## 4. Take the first bill

1. Open **POS / New bill**.
2. Search or tap items, or speak: *“Bill two chai and one samosa.”*
3. Confirm quantities.
4. Choose pay mode (cash, UPI, card, credit).
5. Save / print / share.

That bill should appear in today’s sales.

## 5. Add one customer (optional but useful)

From the bill or the customer list: name + mobile. Next time, search the number to apply credit, history, or WhatsApp follow-up (if you enabled WhatsApp).

## 6. Add staff only when needed

- **Owner** — everything.
- **Manager** — stock, reports, most settings.
- **Cashier** — billing, maybe customers, not delete shop.

Don’t give every helper owner access.

## 7. Offline vs online

- **No internet:** billing, stock on this device, local AI still work.
- **Internet returns:** pending changes sync. Don’t assume another counter sees a sale until sync has run.

If two counters share one shop, keep them online during busy hours or agree who owns which till.

## 8. End of day

1. Open reports → today.
2. Match cash + UPI to the app.
3. Check low-stock alerts.
4. Don’t factory-reset the device; local data lives on it.
